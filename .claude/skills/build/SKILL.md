# Build Tastebench

## Commands

- Type-check only: `pnpm exec tsc -b`. It uses the project references in `tsconfig.json` (`tsconfig.app.json`, `tsconfig.node.json`). `noUnusedLocals` and `noUnusedParameters` are on.
- Full build: `pnpm build` (`tsc -b && vite build`). Output goes to `dist/`, which is gitignored.
- Lint: `pnpm lint` (oxlint, `.oxlintrc.json`: `react/rules-of-hooks` is an error). It exits 1 on `main` because of the `react(refs)` warnings in `src/routes/RoomGate.tsx`; do not add new ones.

## Production build

- The production build needs `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID` and `VITE_FIREBASE_APP_ID`. CI reads them from repository variables.
- A local build without them still compiles, but the app cannot reach Firebase unless `VITE_USE_EMULATOR=true`.

## Fix a build error

1. Run `pnpm exec tsc -b` and fix the first error. Type errors in a test file also fail the build.
2. Run `pnpm test`.
3. Run `pnpm build` once more.
