# Run Tastebench

## Against the emulators (default)

1. In terminal 1, run `pnpm emulators`. It starts Auth on 9099 and Firestore on 8080 for project `demo-rating-rooms`. The emulator UI is off.
2. In terminal 2, run `VITE_USE_EMULATOR=true pnpm dev`.
3. Open the URL that Vite prints. Use a narrow window (390x844) or the browser device mode; the app is mobile first.
4. To act as several people, use separate browser profiles or private windows. Each one signs in anonymously as a new user.

Emulator data is lost when the emulators stop.

## Against the real project

1. Put the four `VITE_FIREBASE_*` values in `.env.local` (gitignored), from the Firebase console web app config.
2. Run `pnpm dev`. Writes go to the real Firestore.

## Production

The site is live at `https://tvp-corp.github.io/Tastebench/` after each push to `main`.

## Stop

Stop the dev server and the emulators with Ctrl+C in each terminal. Check that ports 5173, 8080 and 9099 are free before the next run.
