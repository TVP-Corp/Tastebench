# Vite in Tastebench

- Config: `vite.config.ts` with `base: './'` (relative assets for GitHub Pages under `/Tastebench/`) and the plugins `@vitejs/plugin-react` and `@tailwindcss/vite`.
- Unit-test config is separate: `vitest.config.ts` (jsdom, `setupFiles: ['src/test/setup.ts']`, excludes `tests/emu` and `tests/e2e`).
- Entry: `index.html` → `src/main.tsx` → `src/App.tsx`, inside `StrictMode`.

## Commands

- `pnpm dev`: dev server. Add `VITE_USE_EMULATOR=true` to use the local emulators.
- `pnpm build`: `tsc -b && vite build` into `dist/`.
- `pnpm preview`: serve `dist/`.
- Playwright starts its own server on port 5199 (`playwright.config.ts`).

## Environment variables

- Only `VITE_`-prefixed variables reach the code, through `import.meta.env`. They are public: they ship in the bundle.
- Read them in one place: `src/firebase/app.ts`. Document new ones in `.env.example` and in `.github/workflows/deploy.yml` (the `pnpm build` step `env`).
- `.env.local` and `*.local` are gitignored. Never commit real values.

## Gotchas

- `StrictMode` runs effects twice in development. An effect must return nothing or a cleanup function, or React throws `destroy is not a function` on the second run. `window.scrollTo` returns a Promise in Chrome, so wrap it in braces.
- The build warns about the chunk size (Firebase). That warning is expected.
